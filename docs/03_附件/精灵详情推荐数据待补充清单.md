## Markdown 表格填写规则

下面的 A 表就是主要填写区。为了后续能直接转成 JSON，请按固定格式填写：

- `checked`：填 `true` 或 `false`。
- `manual_action`：只能填 `todo`、`fill_this_form`、`copy_from_same_pet_id`、`not_available`、`ignore_or_merge`。
- `copy_from`：如果 `manual_action=copy_from_same_pet_id`，填写来源，例如 `pet_id=34; real_pet_id=114-1; form=平常的样子`。
- `*_json` 列：填写一行 JSON；没有数据就填 `[]`，未知先保留 `[]` 并在 `note` 说明。
- `note`：自由文本，但不要换行；如果要写竖线，请用中文顿号/逗号替代。

同时也生成了同目录 JSON 模板：`docs/03_附件/精灵详情推荐数据填写模板.json`。如果表格和 JSON 模板同时填写，后续以 Markdown 表格为准。
