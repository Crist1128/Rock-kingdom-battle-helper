## 一、建议优先讨论的机制包

| 机制包 | 推荐先做的技能 | 原因 |
|---|---|---|
| 强制离场 / 延迟返场 | 吓退、恶意逃离、强制重启、加大功率、击鼓传花 | 会补齐后续大量“脱离/替换入场/返场”技能的通用事件结构。 |
| 全技能威力修正 | 排气、提气 | 与已落地的单技能槽威力修正相邻，适合扩展为当前精灵全技能槽修正。 |
| 蓄力 / 受击监听 | 升龙咆哮、怨力打击 | 需要先定“蓄力状态”的事件与快照语义，后续蓄势类技能会复用。 |
| 回合/下回合监听 | 伪造账单、入梦、感电 | 涉及同回合治疗反转、下回合资源修正、离场监听，适合先讨论时机。 |
| 多目标资源与层数统计 | 富养化、月光合奏、毒雾 | 需要补齐场下目标、全队状态层数统计、按极性转换状态等通用操作。 |

## 三、实现落地记录（2026-07-05）

本轮根据审阅结论落地以下能力：

1. `击鼓传花` / `加大功率`：技能本身登记 `pending_next_switch_in`，真正切换仍由 `switch_elf` 执行；切换时分别继承离场精灵正面 `elf` 状态、或给新入场精灵回复 8 能量（上限 10）。
2. `加油`：沿用 `effect_cute_mark`，显示名更新为“萌芽印记”，兼容旧名“萌化印记”；获得正面属性/技能增益时额外 +1 层。
3. `双联脉冲` / `感电`：新增“一回合内多次使用技能”运行时字段 `effective_use_count`，不同于连击；能耗按有效使用次数扣除。`感电` 通过离场监听给本技能槽永久叠加使用次数。
4. `富养化` / `恶念交换` / `毒雾`：分别接入场下多目标资源变化、生命比例互换、敌方当前精灵正面状态按总层数转中毒。
5. `引雷` / `提气` / `月光合奏`：引雷迸发本次威力 +20；提气用既有技能威力层数状态表达 +40/+50；月光合奏基础 1 连击，双方全队萌化总层数每层 +1、无上限。
6. `吓退` / `强制重启` / `恶意逃离`：真实切换仍走 `switch_elf`；当前先在技能事件中写入强制切换/返场提示。`恶意逃离` 的应对防御成功分支已给敌方当前精灵挂“攻击技能能耗 +4，切换清除”。

暂缓项仍按审阅结论保留：`伪造账单`、`入梦`、`升龙咆哮`、`怨力打击`、`折射`、`排气`。
