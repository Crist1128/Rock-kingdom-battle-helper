# 敌方默认配置性格与资质约定 v0.1

> 用途：统一“战斗工作台 → 敌方默认配置”的自动默认值。  
> 本文先作为填写模板，确认后再把规则落到前后端代码里。

---

## 1. 当前问题

敌方默认配置现在有一套临时启发式：

- 高速精灵默认取速度正修；
- 攻击倾向按物攻种族值和魔攻种族值比较；
- 三个 10 资质通常给：生命、速度、主要攻击项。

但前端手动切换性格时，目前不会根据新性格重新同步三个 10 资质。  
例如：

- 原来：`速度+物攻-`，系统给 `生命10 / 魔攻10 / 速度10`；
- 改成：`速度+魔攻-`，期望自动变为 `生命10 / 物攻10 / 速度10`；
- 现在：魔攻10 可能仍保留，没有自动切换到物攻10。

后续应按本文约定实现：**性格变化时，默认资质可自动跟随性格重算；玩家手动改过资质时不应被无提示覆盖。**

## 2. 数据库统计与推荐分界线

统计范围：当前本地数据库 `elf_definition` 中 `deleted_at is null` 且六维完整的 509 个精灵/形态。  
六维顺序：`生命 / 物攻 / 物防 / 魔攻 / 魔防 / 速度`。

### 2.1 六维分布摘要

| 指标 | P50 | P75 | P85 | P90 | P95 | 说明 |
|---|---:|---:|---:|---:|---:|---|
| 生命 | 92 | 110 | 118 | 126 | 135 | 生命 110 已经进入前 25% |
| 物攻 | 84 | 103 | 116 | 126 | 139 | 物攻 120 接近前 15%~20% |
| 魔攻 | 78 | 101 | 110 | 119 | 131 | 魔攻 120 接近前 10% |
| 物防 | 83 | 103 | 115 | 125 | 135 | 单防 115 可作为较高抗性线 |
| 魔防 | 83 | 103 | 112 | 123 | 132 | 单防 115 可作为较高抗性线 |
| 速度 | 85 | 104 | 115 | 115 | 125 | 速度 120 以上约为前 10% |
| 主攻 = max(物攻, 魔攻) | 95 | 114 | 126 | 135 | 147 | 主攻 120 以上约为前 20% |

### 2.2 推荐速度线

| 速度种族 | 数据占比 | 建议定位 | 默认配置倾向 |
|---:|---:|---|---|
| `>= 120` | 48 / 509，约 9.4% | 高速线 | 默认选速度性格；资质点生命、速度、主要攻击项 |
| `110 ~ 119` | 46 / 509，约 9.0% | 中高速线 | 不强制速度性格；若主攻较高，默认选攻击性格，但资质仍可点速度 |
| `< 110` | 415 / 509，约 81.5% | 非高速 | 通常不默认速度性格，除非精灵例外或玩家手动选择 |

结论：按你的游戏体验，**速度性格硬线建议定为 `速度 >= 120`**。  
当前代码曾用 `115` 作为临时阈值；后续实现时建议改为本文的 `120`，并把 `110~119` 作为“攻击性格 + 速度资质”的中高速分支。

### 2.3 推荐攻击线

| 主攻种族 = max(物攻, 魔攻) | 数据占比 | 建议定位 | 默认配置倾向 |
|---:|---:|---|---|
| `>= 130` | 58 / 509，约 11.4% | 强攻击线 | 很适合攻击性格 |
| `>= 120` | 106 / 509，约 20.8% | 高攻击线 | 低速高攻精灵可默认攻击性格 |
| `>= 115` | 126 / 509，约 24.8% | 攻击候选线 | 中高速精灵可考虑攻击性格 + 速度资质 |

结论：**默认配置的攻击线建议用 `主攻 >= 120`**。  
如果速度在 `110~119`，可以放宽到 `主攻 >= 115`，因为这一段本来就存在“性格选攻击、资质点速度”的情况。

### 2.4 推荐物理抗性线与法术抗性线

单看物防/魔防容易漏掉高生命精灵，所以建议同时看“单防”和“生命 + 单防”。

| 抗性类型 | 推荐线 | 数据占比 | 说明 |
|---|---|---:|---|
| 物理抗性线 | `物防 >= 115` 或 `生命 + 物防 >= 220` | 106 / 509，约 20.8% | 能承受物理侧压力，适合把第三资质给物防 |
| 法术抗性线 | `魔防 >= 115` 或 `生命 + 魔防 >= 220` | 102 / 509，约 20.0% | 能承受魔法侧压力，适合把第三资质给魔防 |
| 肉盾候选线 | `生命 >= 110` 且 `min(生命+物防, 生命+魔防) >= 210` | 54 / 509，约 10.6% | 可进入生命性格 + 双抗资质候选 |
| 强肉盾线 | `生命 >= 110` 且同时命中物理抗性线和法术抗性线 | 39 / 509，约 7.7% | 优先默认生命性格 + 双抗资质 |

结论：

- 判断“物抗好不好”：优先用 `物防 >= 115` 或 `生命 + 物防 >= 220`。
- 判断“法抗好不好”：优先用 `魔防 >= 115` 或 `生命 + 魔防 >= 220`。
- 判断“是不是肉盾”：建议先用较宽的肉盾候选线，再用强肉盾线做高置信默认。

### 2.5 推荐分类优先级

默认配置不应该只按单一数值判断，建议按以下顺序：

1. **强肉盾**：命中强肉盾线 → 默认生命性格，资质点生命、物防、魔防。
2. **高速输出**：速度 `>= 120` → 默认速度性格，资质点生命、速度、主要攻击项。
3. **中高速高攻**：速度 `110~119` 且主攻 `>= 115` → 默认攻击性格，资质点生命、主要攻击项、速度。
4. **低速高攻**：速度 `< 110` 且主攻 `>= 120` → 默认攻击性格，资质点生命、主要攻击项、物防或魔防。
5. **普通肉盾候选**：命中肉盾候选线但不是强肉盾 → 默认生命性格或按更强抗性侧补资质，待例外表确认。
6. **均衡/未知**：不命中以上规则 → 默认生命、主要攻击项、速度或更高抗性侧，后续靠例外表修正。

## 7. 确认后代码实现方案

确认本文后，建议按下面方式实现：

1. 新增一个可维护的默认配置规则文件，例如：
   - `backend/app/seed/enemy_default_config_rules.json`
2. 后端 `EstimateService._build_auto_default_config()` 不再硬编码 `速度阈值 115 + 主攻击项`，改为读取规则。
3. 前端敌方默认配置面板增加“自动/手动”概念：
   - 自动模式：切换性格时，按 `性格 → 默认10资质` 自动重算；
   - 手动模式：玩家改过资质后不再自动覆盖；
   - 提供“按当前性格重置资质”按钮。
4. 保存时后端仍负责重新计算默认面板，并校验是否违反实时推导约束。
5. 如果实时推导约束已经明确某个主属性，规则优先级应为：
   - 玩家手动保存配置；
