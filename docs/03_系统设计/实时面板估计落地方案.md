# 实时面板估计落地方案

> 更新时间：2026-06-09
> 状态：当前主流程。旧候选空间、旧 `/candidates/*` 接口、旧候选 service/schema/model/tests 和旧候选表结构已经清理；新功能不得重新引入候选空间落库筛选。

## 1. 目标

敌方配置推算改为“实时面板估计 + 属性约束 + 默认配置校验”：

1. 准备阶段只创建敌方运行时状态和 `EnemyPanelEstimate`。
2. 玩家可以选择一个默认性格/资质配置，用于未知面板时的临时展示。
3. 伤害、扣血百分比、技能出现、速度先后手等 observation 写入 `EnemyPanelEstimateEvidence`。
4. `EstimateService` 根据 observation 更新六维属性约束、unknown factors、confidence、evidence 摘要和最小解释结构。
5. 默认配置保存时按当前约束校验完整面板；冲突时返回明确原因。
6. 事件重放从事件流重建估计档案和 evidence，不读取旧候选状态。

## 2. 当前数据结构

核心表：

- `enemy_panel_estimate`：保存敌方当前估计档案、默认配置、默认面板、属性约束和 unknown factors。
- `enemy_panel_estimate_evidence`：保存每条 observation 或事件对估计档案的影响。

旧表：

- `build_candidate`：已由 Alembic `0006_drop_legacy_candidate_tables` 删除。
- `calculation_cache`：已由 Alembic `0006_drop_legacy_candidate_tables` 删除。

## 3. 默认配置

默认配置只解决“未知面板时先展示什么”的问题，不代表真实配置已经确认。

初始化规则：

- 物攻高于魔攻且速度低于 115：默认性格加物攻减魔攻，资质点生命、物攻、速度。
- 魔攻高于物攻且速度低于 115：默认性格加魔攻减物攻，资质点生命、魔攻、速度。
- 速度大于等于 115 且物攻更高：默认性格加速度减魔攻，资质点生命、物攻、速度。
- 速度大于等于 115 且魔攻更高：默认性格加速度减物攻，资质点生命、魔攻、速度。

当推导结果与玩家当前选择冲突时，系统应自动回退到符合约束的默认配置。玩家仍可在剩余可行范围内重新选择性格和资质。

## 4. 约束更新

实时反推维护的是属性约束，不是候选集合：

- 敌方受到攻击：推导 HP、物防或魔防约束。
- 敌方造成伤害：推导物攻或魔攻约束。
- 速度先后手：先记录不等式、unknown factors 和证据，后续再扩展概率模型。
- 技能出现：记录 confirmed skill，作为后续公式上下文，不触发技能池过滤。

约束交集为空时，不硬改为某个固定配置，而是记录 conflict 和来源 evidence。

## 5. 事件重放

`EventReplayService` 从非作废事件流重建：

- 实时估计档案；
- 估计 evidence；
- 基础运行时状态：切换、HP、能量；
- 最终状态实例；
- 事件后快照链。

后续扩展方向是自动结算副作用重演。重放不得读取已经变化的当前状态冒充历史状态。

## 6. 后续开发边界

允许继续扩展：

- 天气/状态 modifier 对伤害公式和估计约束的影响；
- evidence 解释结构里的公式输入缺项、天气/状态 modifier 概览和未映射规则提示；
- 完整应对/防御结算；
- 速度不等式和概率解释；
- 完整 evidence 解释页；
- 自动结算副作用重放。

禁止恢复：

- 准备阶段生成敌方候选空间；
- observation 逐候选写 `match_score` / `confidence`；
- 把按需枚举结果落库为业务状态；
- 重新开放 `/api/v1/candidates/*`。
